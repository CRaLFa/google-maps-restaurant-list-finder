# Google マップ レストランリスト検索

Google マップ公式のエリア別レストランリスト (「渋谷: トップリスト」等) を日本全国分集めて、地図から探せるようにした Web アプリ。
対象は **日本国内のみ**で、海外のエリアは扱わない。

**https://google-maps-restaurant-list-finder-823271554794.asia-northeast1.run.app**

現在 **191 エリア / 571 リスト**を収録している。

## 何ができるか

- **地図から探す。** エリアごとのピンをクリックすると、そのエリアの 3 種類のリスト (トップリスト / トレンド / 地元で人気) へのリンクが開く。
- **地名で絞る。** 検索ボックスに入れると、ヒットしたエリアだけに地図のピンと左のツリーが絞られる。
  エリア名でも所在地でも引ける (「名古屋」で名古屋市内の区が出る)。
- **都道府県から辿る。** 左のツリーは 都道府県 ▶ 市 ▶ 区 ▶ エリア ▶ リストの入れ子。
  池袋は東京都 ▶ 豊島区 の下に出る。いずれの階層も北から南の順に並ぶ。
- **漏れを報告する。** 一覧に無いエリアを見つけたら、左下のボタンから報告できる。

ブラウザがダークモードなら、地図も含めて暗い配色で表示される。
スマートフォンでは地図とツリーが縦に積まれる。

## なぜ作ったか

Google マップの公式「Google データ エクスポート (Takeout)」では、
**自分が作成したリスト**のスポットは取得できるが、
**他人が作成し自分がフォロー (保存) したリスト**の中身は含まれない。

Google 公式のエリア別リストはまさに後者にあたる。
そのうえ「渋谷: トップリスト」のようなリストはアプリ内で地道に探すしかなく、
全国にどれだけあるのかを一覧する手段が無い。

そこで実機の Google マップアプリを adb + uiautomator で自動操作して共有 URL を集め、
地図上に並べて探せるようにした。

## 構成

| 層 | 使っているもの |
| --- | --- |
| フロント | 単一 HTML + Maps JavaScript API。ビルド無し |
| サーバ | Go / Cloud Run。静的ファイルを `//go:embed` で埋め込んだバイナリ 1 個 |
| データ | Firestore (Native) |
| スパム対策 | reCAPTCHA Enterprise + サーバ側のレート制限 |
| 収集 | Python + adb + uiautomator (実機の Google マップアプリを自動操作)。座標の取得のみ PC のブラウザ |

## 注意

このリポジトリが集めているのは **Google マップ上の公式リストへの共有 URL** であって、
リスト内のスポットの情報ではない。
リストの中身は共有 URL を開いて Google マップ上で見ることになる。

収録範囲は日本国内に限っている。
エリアの階層は 都道府県 ▶ 市区 ▶ エリア という日本の住所の形を前提に組み立てており、
報告フォームの都道府県も 47 都道府県からしか選べない。
海外のエリアを足すには階層の組み立てから作り直しが要る。
